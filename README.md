# Prompt Engineering - Caderno Temático

## 1. Contexto
Este repositório foi criado como entrega do desafio da DIO com foco no tema Prompt Engineering. O objetivo é estudar como estruturar instruções mais eficazes para modelos de IA, testar variações de prompts e consolidar um miniguia prático de revisão.

## 2. Objetivos
- Entender o que é prompt engineering.
- Identificar boas práticas para escrever prompts.
- Testar diferentes estratégias de prompting.
- Registrar erros, ajustes e aprendizados.
- Criar um material reutilizável para estudos futuros.
